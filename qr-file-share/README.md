# QR File Share — project folder

- `index.html` — the actual project page, served at `s-rajkumar.github.io/qr-file-share/`
- `cover.jpg` — add the main cover image here (shown on the home page card and at the top of this page). Until it's added, a placeholder graphic shows automatically.
- `screenshots/` — drop screenshots in here, then list their filenames in the `SCREENSHOTS` array inside `index.html` (search for `SCREENSHOTS`) to show them in the gallery strip.
- `privacy-policy.html` — edit the bracketed sections with real details before publishing to the Play Store / Microsoft Store.

## To fill in later
